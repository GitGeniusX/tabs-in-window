# Changelog

All notable changes to this project are documented in this file.

## 0.2.0 - 2026-04-23

- Improved tab card header layout so long titles align more cleanly.
- Replaced the `Close` text action with a compact `×` control to free up more space for tab names.
- Added a hover/focus tooltip that reveals the full tab title and hostname.
- Fixed tooltip layering so expanded text stays above neighboring cards.
- Added project documentation and installation instructions in `README.md`.

## 0.1.0 - 2026-04-23

- Initial Manifest V3 release of Window Tab Grid.
- Added the full-page tab manager for the current browser window.
- Added search, pinned/unpinned filtering, and sorting by last accessed time, tab order, and title.
- Added tab activation and close actions directly from the grid.
